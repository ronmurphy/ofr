OFR sprite editor

Draw a creature or an item pixel by pixel, give it colour variants, and save it as a small text file the game can read (and a PNG to look at). Start from a template, from any creature's or item's icon in the game (from the game: a rough pictogram in its own colour, to draw over), or from nothing. Keys: P pencil, F fill, R rectangle, L line, I pick a colour, M mirror, Ctrl+Z undo, Ctrl+Y redo. Right-click erases.
