OFR vault editor

Paint a room, watch it check itself, save the .txt into assets/vaults/. Same rules as tests/vault_lint.gd — if it passes here it will load in the game.

Cave vaults (kind: cave): press generate cave for a shape grown by the game's own rules, then paint it. Until the game reads kind: cave (tools/CAVE_VAULTS_GAME_SIDE.md), save them into tools/cave_vaults/, NOT assets/vaults/ — the game would place them as rooms.

Palette

Click to paint, drag to fill. Right-click erases back to outside-the-vault.
